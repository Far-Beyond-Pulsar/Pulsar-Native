# helio-voxel-world

Destructible voxel worlds, the data: grid, terrain generators, edits, queries,
planet maps and features, with the WGSL mirrors that evaluate the same field
on the GPU. No GPU dependency. The system as a whole (goals, invariants,
measuring) is documented with its renderer:
[`helio-pass-voxel-planet/README.md`](../feature/README.md).
